Agent Tracking Slackbot

Proactive Slack notifications when AI-Deep agents misbehave — plus a daily LLM-as-a-judge signal to catch quality regressions before they become incidents.

The Problem

Agent activity tracking is moving to a virtual key per agent model. When a slug is created in AI-Deep, a virtual key is automatically provisioned and stored on the agent config. All LLM calls for that agent are made under its key — giving the proxy native per-agent visibility with no tagging required.

But creators still have to manually monitor dashboards to catch runaway costs, silent failures, or stuck agents. This design adds an alerting layer so creators are pinged automatically.

Key Design Decisions

  • ✓In-memory dedup — no DB needed; restarts are acceptable
  • ✓Slack failures log a warning, never crash the task
  • ✓Email → Slack ID resolved once, cached for session

What Creators See

Alerts land in a shared #ai-deep-alerts channel. The agent creator is @-mentioned automatically via their poc_email.

  • ✓No Slack app to install for creators — just a channel to join
  • ✓Single bot token with minimal scopes: chat:write + users:read.email
  • ✓If email lookup fails, message still sends (without @mention)
  • ✓4-hour cooldown prevents repeat noise for same condition

Phase 3: LLM-as-a-Judge Performance Tracking

How It Works

📝
Creator sets evaluator_question on their slug config (optional)
↓
⏰
Daily job runs once at configurable time (default 06:00 UTC)
↓
🎲
Sample N recent outputs from the LLM proxy logs (default 25)
↓
🧑‍⚖️
Judge each output with cheap model — pass / fail verdict
↓
📉
Compare pass rate vs. 7-day rolling baseline
↓
💬
Alert if drop > threshold (default 10%)

Cost Analysis

Per agent · per day
200 samples × ~300 tokens (input + output)
= ~60,000 tokens / agent / day
@ GPT-4o-nano pricing ≈ < $0.01 per agent
Even at 100 active agents: ~$1/day total

New Config Fields

evaluator_question: str | None = None
# e.g. "Is this caption accurate
#       and geographically relevant?"

# optional overrides (in alert_overrides):
evaluator_sample_size: int | None = None
    # default: 200
evaluator_model: str | None = None
    # default: gpt-4o-nano
evaluator_drop_threshold_pct: float | None = None
    # default: 10.0
Judge prompt template
"Does this caption accurately summarize
the provided source text?
Caption: {sampled_output}
Source: {source_text}
Answer: PASS or FAIL only."

Per-Agent Config Fields

New fields on agent config:

virtual_key_id: str            # set at slug creation
alert_overrides:               # optional
  daily_cost_usd: 25.0        # override $10 default
  inactivity_hours: 48.0      # override 24h default
  token_spike_multiplier: 5.0 # override 3× default
